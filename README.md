# 🚀 Data Structures & Algorithms in Java

A comprehensive collection of **Data Structures and Algorithms (DSA)** implemented in **Java**. This repository is designed to help students, developers, and coding interview aspirants strengthen their problem-solving skills through clean, well-structured, and optimized solutions.

## 📌 Features

* ✅ Beginner to Advanced DSA concepts
* ✅ Clean and well-documented Java code
* ✅ Optimized solutions with time & space complexity
* ✅ Interview-focused coding problems
* ✅ LeetCode, Coding Ninjas, and other platform solutions
* ✅ Regular updates with new problems

## 📂 Topics Covered

* Arrays
* Strings
* Searching & Sorting
* Linked Lists
* Stacks
* Queues
* Hashing
* Recursion & Backtracking
* Trees
* Binary Search Trees
* Heaps
* Graphs
* Dynamic Programming
* Greedy Algorithms
* Bit Manipulation
* Sliding Window
* Two Pointers
* Tries
* Disjoint Set Union (DSU)

## 🛠️ Tech Stack

* **Language:** Java
* **IDE:** IntelliJ IDEA / Eclipse / VS Code
* **Version Control:** Git & GitHub
